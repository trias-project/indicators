Damiano Oldoni

This document describes the pre-processing of occurrence data of alien species in Belgium. The outputs of this pipeline will be used as input for modelling.

Load libraries:

2.4 Filter data

2.4.1 Cells in occurrence cubes not in EEA Belgian grid

The occurrence cubes were created based on GBIF occurrences filtered using country = BE. The cell codes were then created by manipulating the coordinates as strings, i.e. no spatial filter with the EEA grid was applied. So, it can happen that (few) cells in the cube are not linked with occurrences in Belgian territory as country = BE is in rare cases not enough. We remove them by using the geopackage containing the regional information of the EEA grid cells as shown in the following step. The regional information will be added at a later stage.

Read the EEA grid with regional information from utm1_bel_with_regions.gpkg in data/output:

gpkg_path <- here::here("data", "output", "utm1_bel_with_regions.gpkg")
eea_grid_regions <- sf::st_read(gpkg_path)

eea_grid_regions %>% head()

Notice that the column isBelgium is the union of the columns isFlanders, isWallonia and isBrussels. The 15km buffer zone and the maritime federal zones are not covered. At the moment we will not use the column isBelgium as occurrences on the maritime federal zones or in proximity of the coast would be otherwise excluded. Still, notice that these areas cover almost 40% of the EEA grid:

eea_grid_regions %>%
  # Transform to data.frame
  as.data.frame() %>%
  # Count the number of cells in Belgium
  dplyr::count(isBelgium) %>%
  # Add percentage as a column
  dplyr::mutate(percentage = n / sum(n) * 100)

We identify the rows to remove in alien species occurrence cube, df, and baseline, df_bl, by doing an anti_join:

df %>%
  dplyr::filter(!eeaCellCode %in% eea_grid_regions$CELLCODE)
df_bl %>%
  dplyr::filter(!eeaCellCode %in% eea_grid_regions$CELLCODE)

We remove them:

df <- df %>%
  dplyr::filter(eeaCellCode %in% eea_grid_regions$CELLCODE)
df_bl <- df_bl %>%
  dplyr::filter(eeaCellCode %in% eea_grid_regions$CELLCODE)

2.4.2 Taxa in unified checklist without occurrences

There is a group of taxa defined in the unified checklist which are not present in the occurrence data, i.e. the presence of these taxa, although confirmed by authoritative’s checklists, is still not sustained by observations:

alien_taxa_without_occs <-
  taxa_df %>%
  dplyr::filter(!acceptedKey %in% df$taxonKey) %>%
  dplyr::arrange(nubKey)
alien_taxa_without_occs

where taxonKey is the unique GBIF identifier of the taxon as published in the unified checklist, while nubKey is the unique GBIF identifier of the taxon in the GBIF Backbone Taxonomy. The field acceptedTaxonKey is equal to nubKey if nubKey is not a synonym. We save this data.frame as alien_taxa_without_occurrences.tsv in data/output:

write_tsv(
  alien_taxa_without_occs,
  here::here("data", "output", "alien_taxa_without_occs.tsv"),
  na = ""
)

3 Pre-processing

3.1 Extract x-y coordinates from cellcodes

Extract coordinates from column eeaCellCode. For example, the coordinates of cellcode 1kmE3895N3116 are x = 3895 and y = 3116:

df_xy <-
  df %>%
  dplyr::distinct(eeaCellCode) %>%
  dplyr::bind_cols(
    dplyr::tibble(
      x = unlist(stringr::str_extract_all(unique(df$eeaCellCode),
        pattern = "(?<=E)[0-9\\-]+"
      )),
      y = unlist(stringr::str_extract_all(unique(df$eeaCellCode),
        pattern = "(?<=N)[0-9\\-]+"
      ))
    ) %>%
      dplyr::mutate(across(where(is.character), as.integer))
  )

Preview:

df_xy %>% head()

Do the same for baseline data:

df_bl_xy <-

3.2 Apply temporal and spatial restraints

From the distribution information, retrieve the first year of introduction (first_observed) for each taxon:

distributions <- distributions %>%
  # Parse eventDate to get year of introduction. Get the characters before `/` if present and convert to numberic if not character `"NA"`
  dplyr::mutate(
    first_observed = case_when(
      is.na(eventDate) ~ NA_real_,
      stringr::str_detect(eventDate, "/") ~ as.numeric(stringr::str_extract(eventDate, "^[0-9]+"))
    )
  )

Add such information to the taxonomic information:

taxa_df <- taxa_df %>%
  dplyr::left_join(
    distributions %>% dplyr::select(taxonKey, first_observed),
    dplyr::join_by(taxonKey)
  )

Select alien species introduced after 1980 (year_of_introduction: 1950) or whose date of introduction is not known:

year_of_introduction <- 1950

recent_alien_species <-
  taxa_df %>%
  # Lower limit on date of first introduction if present
  dplyr::filter(first_observed >= year_of_introduction | is.na(first_observed))

Number of (accepted) taxa recently introduced or whose introduction year is not specified:

length(unique(recent_alien_species$acceptedKey))
## [1] 3741

Alien species excluded as first introduction date is earlier than 1950:

old_introductions_taxa <-
  taxa_df %>%
  dplyr::filter(first_observed < year_of_introduction)
old_introductions_taxa

We save them in file taxa_introduced_in_BE_before_1950.tsv in data/output:

write_tsv(old_introductions_taxa,
  here::here(
    "data",
    "output",
    paste0(
      "taxa_introduced_in_BE_before_",
      year_of_introduction,
      ".tsv"
    )
  ),
  na = ""
)

Remove from the occurrence cubes the taxa introduced before 1950 and add x-y coordinates:

df <-
  df %>%
  # Recently introduced taxa
  dplyr::filter(taxonKey %in% recent_alien_species$acceptedKey) %>%
  dplyr::left_join(df_xy, by = "eeaCellCode")

Add x-y coordinates to the baseline cube:

df_bl <-
  df_bl %>%
  dplyr::left_join(df_bl_xy, by = "eeaCellCode")

Notice that the occurrence cubes are already temporally limited to GBIF occurrences observed after 1980.
