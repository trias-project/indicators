Detect appearing and reappearing species

Damiano Oldoni

Toon Van Daele

Tim Adriaens

2026-05-21

In this document we analyze the Belgian datacube to detect possible (re)appearing taxa in the last year. Such detection is based on some basic rules instead of using GAM (Generalized Additive Models) as the number of GBIF observations decreases sensibly during the current year as effect of a publishing delay. We also take into account the appearing/reappearing in protected areas as additional warning.

3 Detect appearing and reappearing species

For emerging trends in the next workflow we do not take into account the present year and the last year as data publication delays can occur. However, for getting a list of appearing and reappearing species we can of course consider the present year and the last year as evaluation years.

# First year to consider for evaluation of (re)appearing taxa
first_year <- lubridate::year(Sys.Date()) - 2 - 2

# First evaluation year
last_year <- lubridate::year(Sys.Date())

# Evaluation years
years <- seq(first_year, last_year)

3.1 Appearing species

We define the function get_appearing_taxa for detecting appearing taxa (this function could be generalised and added to TrIAS package trias later):

#' @param cube data frame with occurrence cube. Columns `taxonKey` and `taxonName` must be present.
#' @param first_eval_year first year to consider for evaluation of appearing taxa
#' @return data.frame with appearing taxa
get_appearing_taxa <- function(cube, first_eval_year) {
  cube %>%
    dplyr::group_by(taxonKey, taxonName) %>%
    dplyr::summarise(
      first_year = min(year),
      .groups = "drop"
    ) %>%
    dplyr::filter(first_year >= first_eval_year)
}

3.2 Reappearing species

We define the minimum latency (in years) before we speak about reappearance. For example, a latency time window of 5 years means that we consider a taxon reappearing in 2025 if observations occur in 2025 and 2019 or before:

years_latency <- 5

We define the function get_reappearing_taxa for detecting reappearing taxa (this function could be generalised and added to TrIAS package trias later):

#' @param cube data frame with occurrence cube. Columns `taxonKey` and `taxonName` must be present.
#' @param first_eval_year first year to consider for evaluation of appearing taxa
#' @param latency_threshold minimum latency (in years) before we speak about reappearance. For example, a latency time window of 5 years means that we consider a taxon reappearing in 2025 if observations occur in 2025 and 2019 or before.
#' @return data.frame with reappearing taxa
get_reappearing_taxa <- function(
  cube,
  first_eval_year,
  latency_threshold
) {
  reappearing_species <- cube %>%
    dplyr::group_by(taxonKey, taxonName) %>%
    dplyr::summarise(
      # set to min(year) from the first evaluation year if there are
      # occurrences in those years, otherwise set to NA. This way we can
      # filter for species that reappear in the evaluation years or later.
      reappearance_year = ifelse(
        any(year >= first_eval_year),
        min(year[year >= first_eval_year]),
        NA_integer_
      ),
      years_without_occurrences = ifelse(
        any(year >= first_eval_year) & any(year < first_eval_year),
        min(year[year >= first_eval_year]) - max(year[year < first_eval_year]),
        NA_integer_
      ),
      .groups = "drop"
    ) %>%
    dplyr::filter(
      !is.na(reappearance_year) &
        !is.na(years_without_occurrences) &
        years_without_occurrences >= latency_threshold
    )
}

3.2.1 Reappearing species in Belgium

Apply function defined above over the entire cube referring to Belgium:

reappearing_taxa_be <- get_reappearing_taxa(
  cube = df,
  first_eval_year = first_year,
  latency_threshold = years_latency
) %>%
  dplyr::arrange(desc(reappearance_year), desc(years_without_occurrences)) %>%
